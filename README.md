messaging-accounts
==================

Messaging account definitions, provides account definitions for various IM accounts.

Currently available:

Jabber (XMPP)

Matrix

Removed (network shut down, or vendor sunsetting the product):

Gadu-Gadu, (Novell/OpenText) Groupwise, ICQ, QQ, (IBM/HCL) Sametime, Sipe, Skype, Yahoo
